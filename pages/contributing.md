# Contributing

Small PRs that fix one thing please. If you need something to do, the good first issues are on [Community](community.md) <kbd>0.4</kbd>.

Code: the org [contributing guide](https://github.com/goome-ui/.github/blob/main/CONTRIBUTING.md), then the one in that repo, like [c-goome's](https://github.com/goome-ui/c-goome/blob/dev/CONTRIBUTING.md).

Docs: [CONTRIBUTING.md in the docs repo](https://github.com/goome-ui/docs/blob/dev/CONTRIBUTING.md). Typos and wrong samples help the most.

Every PR goes against **dev**, a bot closes anything else.

Security holes dont go in issues, read [SECURITY.md](https://github.com/goome-ui/.github/blob/main/SECURITY.md) and tell me privately.
